## LGP Battery Monitor v0.1.0-beta.1 (beta)

### Overview
First public beta of a lightweight Windows tray app that shows the battery of a Logitech G Pro X Superlight 2 without Logitech G HUB, using HID++ 2.0 directly.

### Features
- Real battery percentage and charging state (shown only when the device reports it), connection state, last-updated time.
- Tray icon with live percentage, tooltip and menu (Show Battery, Settings, Start with Windows, Check for Updates, About, Exit).
- Compact dark popup, settings and about windows.
- Refresh every 30 s – 5 min; faster retry while the mouse sleeps.
- Low (20 %) / critical (10 %) notifications with de-duplication.
- Optional per-user autostart, launch minimized, single instance, manual update check.

### Improvements / bug fixes
Initial release — nothing to compare against.

### Installation
- **Installer:** run `LGP-Battery-Monitor-0.1.0-beta.1-setup.exe` (per-user, no admin needed).
- **Portable:** run `LGP-Battery-Monitor-0.1.0-beta.1-portable-x64.exe`.
- Verify files against the SHA256 checksums below.

### Known limitations
- Verified only with a Superlight 2 on a LIGHTSPEED receiver, Windows 11. USB-cable mode and other devices are untested.
- A sleeping mouse cannot be read; the app shows "Mouse not responding" (and the last known value).
- ~80 MB RAM while idle (UI toolkit).
- Not tested on Windows 10.

### Signing
**Unsigned.** SmartScreen / antivirus warnings are likely. SignPath Foundation signing is prepared but not enabled (requires an approved application). See `docs/code-signing.md`.
